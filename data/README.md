# Data

`hotel_bookings.csv` — *Hotel booking demand* dataset (119,390 bookings × 32 columns).

* Kaggle: https://www.kaggle.com/datasets/jessemostipak/hotel-booking-demand
* Original paper: N. Antonio, A. de Almeida, L. Nunes (2019). *Hotel booking demand datasets.*
  Data in Brief, 22, 41–49. https://doi.org/10.1016/j.dib.2018.11.126

If the CSV is not in this folder, download it from Kaggle and save it here as `data/hotel_bookings.csv`.
The data is anonymised (no personal information) and released under CC BY 4.0.
